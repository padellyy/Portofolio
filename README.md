## 📂 Project

### 1. Telco Customer Churn Prediction
A data science and analytics project focused on predicting customer churn. Key highlights include:
* **Machine Learning Modeling:** Conducted a comprehensive model comparison between **Logistic Regression, Random Forest, and XGBoost** to identify the best-performing predictive model.
* **Business Intelligence Dashboard:** Developed an interactive BI dashboard designed to answer specific business problems, track essential company KPIs, and deliver actionable insights for stakeholders.

### 2. Hybrid TMDB Movie Recommendation System using mBERT + XLM-RoBERTa and Cross-Encoder
A content-based movie recommender built on the TMDB dataset. It retrieves candidates with hybrid transformer embeddings (mBERT + XLM-RoBERTa small) and ranks them with a transformer-based cross-encoder, deployed as an interactive web app using Streamlit.

### 3. Online Retail Customer Retention and Segmentation Analysis
A customer analytics project on the UCI Online Retail II dataset that measures customer retention with cohort analysis and groups customers into behavioral segments using RFM (Recency, Frequency, Monetary).

### 4. Dataco Smart Supply Chain Analytics, ETL with KNIME and Dashboard via Power BI
An end-to-end analytics project on the DataCo Smart Supply Chain dataset, covering the full pipeline from raw data to dashboard. Key highlights include:
* **ETL with KNIME:** Cleaned and transformed the raw order data, then loaded it into a MySQL database.
* **Dimensional Modeling:** Designed a star schema with one fact table and multiple dimension tables (customer, product, shipping, date, and location).
* **Power BI Dashboard:** Built an interactive dashboard connected to the MySQL database to track sales, profit, and delivery performance.
